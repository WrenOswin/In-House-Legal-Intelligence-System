TASK RULES (capstone doc section 13)
==========================================================================================
Output: prediction.json = {query_id: [exactly 7 unique candidate ids of the test pool, best first]} for all
237 test queries, zipped. Metric: micro-F1@7 (primary), micro-P@7, micro-R@7; gold sets are not truncated.
Each split's queries must be ranked against that split's own pool only.
>= 4 substantially different experiments: >= 3 different fine-tuning/PEFT techniques (LoRMA compulsory) +
>= 1 knowledge distillation (larger teacher -> smaller student). Allowed technique list (13.2.1): full FT,
partial FT, QLoRA, LoRMA, prefix tuning, prompt tuning, IA3, KD - plain LoRA / adapters are NOT on it.
Pooling / similarity / ranking objective choices don't count as techniques. Minimum 6 submissions (README;
doc section 6.5 says 4 - aim for 6). Phase 7 window 3-7 Nov, Codabench takes 15-30 min per submission.

Training design (train.py docstring has the details):
  bi-encoder, maxsim score, tau 0.05; per step 16 train queries x (1 random gold + 1 BM25-trigram hard
  negative from the top 30), multi-positive InfoNCE over all in-batch candidates; chunk selection by BPE-trigram
  overlap (4 chunks per case in training, 16 evenly spaced at inference); GradCache (two passes, exact because
  dropout is 0); 400 steps; dev evaluated every 100 steps; checkpoint = best fused dev F1@7. Submission =
  z(BM25) + w * z(model) with w picked on dev (the model-alone ranking is logged too).
  KD (P5): (1-a) InfoNCE + a KL(teacher in-batch distribution || student), teacher = P1's full train-pool maxsim
  scores.
Smoke test (A_d560 full, 20 steps, unthrottled): 6 s/step, 22k tok/s, 1.33 GB peak VRAM; dev encode 46 s.
