- src\seq2seq.py: Summarizer for all four architectures, built on the unchanged Phase-1 weights:
    A, C, D: <|bos|> source <|sep|> summary <|endoftext|>, loss on summary tokens only (A/D causal as
             pretrained; C prefix-LM: bidirectional source + segment embedding 0/1; D keeps its 256-token

    B:       encoder-decoder as Fusion-in-Decoder: each 512-token source chunk encoded separately (encoder max
             768), decoder <|bos|> summary cross-attends to all chunk encodings
  RoPE position interpolation (positions / 2) for A and C (pretrained 1,024 -> 2,048 = 1,533 source + 512
  summary) and for B's decoder (256 -> 512). Own forward passes -> logits only on summary positions,
  Houlsby adapters, batched left-padded KV-cache generation (greedy/sampling, repetition penalty,
  no-repeat-n-gram, min/max new tokens).
  Checked (src\check_seq2seq.py): teacher-forced loss identical to the original Phase-1 models for A, B, C, D
  (e.g. A d560 2.32700 vs 2.32700); batched cached greedy generation identical to naive greedy in fp32. In
  bf16, D once flipped a near-tie (p 0.1512 vs 0.1500) - rounding, not a bug.
- src\train.py (driver), run.py (one JSON config), run_queue.py (S1-S7), teacher_gen.py (KD data),
  decode_sweep.py (decoding study / decoding-variant submissions).
- Training: AdamW, cosine schedule with 5% warmup, 16 docs per step, micro-batches <= 4,096 tokens, bf16
  autocast, no activation checkpointing (faster, peak 4.2 GB for A d768). Model selection by teacher-forced
  val loss on all 300 val docs, twice per epoch, patience 3. At the end: best checkpoint generates val
  summaries (ROUGE-1/2/L, words, 4-gram repetition) and test summaries (submission).
  Default decoding: greedy, max_new 512, min_new 200, no-repeat-4-gram, no repetition penalty.
- Laptop safety as Phase 5: duty 0.6 (GPU sleeps 40% of the time), below-normal priority, 2 CPU threads,
  vram_fraction 0.75.

Long-document strategy (all runs): importance-based context selection. summ.Salience = ridge regression
on hashed word uni+bigram TF-IDF (2^18 features) + 20 position bins, first/last-sentence flags and length,
fitted on 4,000 train docs to predict each sentence's salience (see 2); top sentences kept in document order
until the source budget is full (first sentence always kept). Plus RoPE interpolation (A, C) and FiD (B).

------------------------------------------------------------------------------------------
6. OBSERVATIONS
------------------------------------------------------------------------------------------
1. Truncation loses a lot: the first ~1.3k tokens of a judgment contain only ~57% of the summary's content
   words (whole doc 90%); importance-based selection raises this to ~64% at the same budget.
2. ...but better input coverage did not give better summaries: S7 (first tokens) = S2 (selected sentences)
   on every metric (ROUGE-1 0.387 vs 0.388). The bottleneck is the model, not the input selection.
3. Model scale and the Phase-1 representations dominate: ranking A d768 (0.472) > A d560 full FT (0.459) >
   C Houlsby (0.431) > A d560 KD (0.426) > D LoRA (0.388) > B FiD (0.374) - the Phase-1 order A > C/D > B
   again. The Phase-1 LMs are useful: S1 beats the lead-500 extractive baseline (0.464) with fewer words.
4. Parameter-efficient vs full: 3.8M trainable LoRMA parameters on the 140M A beat full FT of the 58M A
   (0.472 vs 0.459); for the 54-60M models, PEFT runs moved val loss much less than full FT (D LoRA -0.27,
   C Houlsby -0.83, A d560 full FT -1.01).
5. Knowledge distillation (sequence-level) did NOT help: KD student S5 0.426 vs the same student without a
   teacher S6 0.459. It keeps 90% of the teacher's ROUGE-1 at 40% of the parameters and 79% of its
   generation time, but S6 keeps 97% with no teacher. Teacher summaries are shorter and contain
   hallucinated numbers (31% of the teacher's numbers are not in the source) - the student inherits them
   (S5 0.527 vs S6 0.475). Opposite of Phases 4-5, where soft-label KD on classification helped.
6. Faithfulness follows quality: the better the model, the more it copies from the source (novel bigrams
   0.33 for S1 vs 0.58 for S4) and the fewer numbers it invents (0.31 vs 0.79). "Abstractive" text from the
   weaker models is mostly hallucination.
7. Redundancy is low: no-repeat-4-gram decoding keeps repeated 4-grams at 0.04-0.17% (references 3.8%,
   because legal phrases recur) and no sentence is repeated; local loops still appear (S1 sample).
